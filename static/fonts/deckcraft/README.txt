Fonts loaded into DeckCraft with its font.add command (static/js/deckcraft-fonts.js): the web build
bundles a single face, so decks drawn in Inter and a monospace font need these.

Inter 4.1        https://github.com/rsms/inter/releases/tag/v4.1        (extras/ttf, SIL OFL 1.1)
JetBrains Mono 2.304 https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304 (fonts/ttf, SIL OFL 1.1)
